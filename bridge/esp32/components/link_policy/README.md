# link_policy

Which role may send which vendor command (Link spec 6.3), from
`policy/commands.json`.

| File | What it does | Portable |
|------|--------------|----------|
| `include/link_policy.h`, `link_policy.c` | Looks up a command's class (`read`, `control`, `config`) and whether a role allows it. Unknown codes are `config`. | yes |
| `link_policy_table.h`, `link_policy_table.c` | The table and the spec version it came from, generated by `tools/gen_policy.py`; do not edit by hand. CI checks it matches the JSON. The header is private: other components use `link_policy.h`. | yes |

Public API: `link_policy_class()`, `link_policy_role_allows()`,
`link_policy_role_name()`.

Tests: `test/host/test_link_policy.c`.
